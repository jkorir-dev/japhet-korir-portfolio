# Japhet Korir | Personal Portfolio Website

A clean, modern single-page portfolio website designed to present professional experience, developmental engineering skills, and feature core frontend technical applications.

## Live Demo
- **GitHub Pages Link:** [https://github.io](https://github.io)

## Features
- **Semantic Structure Architecture:** Clean single-page document section layouts matching validation structures.
- **Dynamic Content Injection:** Development skills array and project data tables rendered programmatically onto the DOM tree using JavaScript loops.
- **Responsive Dark Theme UI Grid:** Sleek charcoal variable values scaling comfortably across standard layout environments.
- **Active Navigation Matrix:** Anchor link paths driving fast section transition scroll behaviors.

## Technologies Used
- HTML5 (Semantic elements structure)
- CSS3 (Custom design variables matrix, Flexbox, and CSS Grids)
- Modern Vanilla JavaScript (ES6 Arrays mapping and dynamic object loops)
- Git & GitHub Version Control Management

## How to Run This Project Locally
1. Clone this repository down to your computer using your terminal:
   ```bash
   git clone git@github.com:jkorir-dev/phase-0-portfolio-project.git
   ```
2. Navigate inside the newly downloaded project directory:
   ```bash
   cd "Japhet korir-portfolio"
   ```
3. Open the `index.html` file inside any standard browser window to launch the application.
